A deterministic 1024x1024 8-bit pixel newspaper front page summing up the world news of Monday 23 November 2026 — 36 stories led by COP31, the Merkury sinking and Hormuz, on pale-mint paper with CryptoPunk-style pixel art. The image is held in this repository as `entry.png.b64` (base64 of the PNG).

## Run it

```sh
python3 main.py
```

`main.py` (Python standard library only, no network, no third-party packages) decodes `entry.png.b64` and writes it to `/output/entry.png` when `/output` exists. Running it twice writes byte-identical files.
